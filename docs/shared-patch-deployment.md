## Remaining decisions before broader MVP deployment

The existing native `read-only` profile has full-host-read semantics in the pin. A bounded synthetic trial is not proof that model tools cannot read auth. Broader real-code deployment requires a separately verified restricted native permission profile/tool strategy that preserves the owner refresh design and existing strict guard. Checker v1 intentionally rejects Node/V8 and generic builds; aggregate resource isolation and immutable project dependencies for React/Node checks require another architectural release. Those gaps keep full MVP readiness false even if the narrow Python acceptance passes.

Fresh model turns and installation are not requested automatically by this document, and none were run while producing it.
